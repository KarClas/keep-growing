# Keep Growing — Pitch Deck

Presentation deck built with [Reveal.js](https://revealjs.com/) for the hackathon pitch, styled with the Keep Growing "Gartenregal" warm paper design system and color palette.

## How to View

You can open the slide deck directly in your browser:

```bash
open pitch/index.html
```

Or serve it locally:

```bash
python3 -m http.server 8000 -d pitch
# or
npx serve pitch
```

Then open `http://localhost:8000` in your browser.

## Navigation

- **Space / Right Arrow**: Advance to next slide
- **Left Arrow**: Previous slide
- **Up / Down Arrows**: Navigate between vertical sub-slides
- **Esc / O**: Slide overview grid
- **S**: Presenter speaker notes
